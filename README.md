# PROMAX مناديب — الموبايل أبلكيشن

Flutter، متصل بـ **PROMAX ERP** عن طريق API. رولين: **كاش فان** و**كورير توزيع**.

---

## التشغيل

### 1. شغّل الباك اند الأول

```bash
cd C:\xampp\htdocs\ProMax\Promax-erp
php artisan serve
```

لازم يفضل شغّال طول ما بتجرب الأبلكيشن.

### 2. شغّل الأبلكيشن

```bash
cd C:\xampp\htdocs\ProMax\Promax-app
flutter pub get
flutter run           # على الإيموليتور
```

## عنوان السيرفر

الأبلكيشن بيظبطه لوحده:

- **إيموليتور أندرويد** → `http://10.0.2.2:8000/api`
- **ويندوز / ويب** → `http://127.0.0.1:8000/api`

لو بتجرب على موبايل حقيقي على نفس الشبكة، افتح **"عنوان السيرفر"** في شاشة الدخول وحط
`http://<IP بتاع جهازك>:8000/api`، وشغّل السيرفر بـ:

```bash
php artisan serve --host=0.0.0.0
```

## السايكل

### مندوب الكاش فان
1. لوجين → الداشبورد: مبيعات اليوم، الزيارات، العهدة المتبقية
2. الزونز → يختار الزون → **يدوّر على العميل** (اسم / عنوان / تليفون) أو يفلتر (الكل / لسه / تمت)
3. كارت العميل: تصنيفه، عقده وخصمه، ورصيده المستحق
4. **تشيك إن** → **فاتورة** (بحث في الأصناف، خصم العقد تلقائي، والآجل مقفول للعملاء الخطر) → **تشيك أوت**
5. **عميل جديد**: يسجل المحل/الجيم ويبعت طلب للمدير، والرد بيوصله نوتفيكيشن

### الكورير
1. لوجين → الريكوستات (POs من Gourrmet / Rabbit اللي المدير نزّلها عليه)
2. يفتح الـ PO → **وصلت المكان** → **تم التسليم** (بيخصم من عهدة العربية)

كل حاجة بتتسجل لايف في تراكينج الـ ERP.
